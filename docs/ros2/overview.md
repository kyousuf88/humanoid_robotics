# ROS 2 Fundamentals

**ROS 2 (Robot Operating System 2)** is the middleware that connects sensors, actuators, and AI modules.

It provides:

- Nodes: independent processes  
- Topics: publish/subscribe message streams  
- Services: request/response interfaces  
- Actions: long-running operations with feedback  

You will learn how to:

1. Structure ROS 2 packages  
2. Use Python nodes (`rclpy`)  
3. Interface your AI agents with robot hardware  
4. Describe robot kinematics using URDF  

By the end of this module, you will control a humanoid robot’s basic motions programmatically.
