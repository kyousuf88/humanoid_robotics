# NVIDIA Isaac Robotics Platform

Isaac provides:

- Photorealistic simulation (Isaac Sim)  
- Hardware-accelerated AI (Isaac ROS)  
- Navigation (Nav2)  
- VSLAM and perception modules  

You will use Isaac to simulate humanoid perception, plan bipedal locomotion, and integrate AI-driven behaviors.
