# Capstone Project Details

Project stages:

1. Receive natural language command  
2. Plan path and actions  
3. Navigate obstacles  
4. Identify and manipulate objects  
5. Execute task autonomously  

Deliverables:

- Simulation environment setup  
- ROS 2 packages  
- AI perception pipeline  
- Final demonstration video
