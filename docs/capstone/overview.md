# Capstone Project: The Autonomous Humanoid

The capstone integrates **all modules**:

- Voice command reception (VLA)  
- Perception and navigation (Isaac, sensors)  
- Motion and manipulation (ROS 2, mechanics, actuators)  

Students build a **simulated humanoid** that can understand and execute tasks in a human-like environment.
