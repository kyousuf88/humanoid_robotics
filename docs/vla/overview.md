# Vision-Language-Action (VLA)

VLA integrates:

- **Vision**: Camera input, scene understanding  
- **Language**: Natural language instruction  
- **Action**: Robot executes commands  

Example workflow:

1. Voice command: "Pick up the red cube"  
2. NLP interprets the command  
3. AI planner maps command → actions  
4. ROS 2 executes actions on hardware or simulation
