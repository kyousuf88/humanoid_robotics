# Actuators & Motors

Actuators convert electrical signals to **mechanical motion**:

- Servos: precise rotation control  
- DC Motors: continuous rotation  
- Stepper Motors: incremental rotation  

Key parameters:

- Torque  
- Speed  
- Accuracy  

These components drive limbs and joints.
