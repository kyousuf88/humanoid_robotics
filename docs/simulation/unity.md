# Unity Simulation

Unity provides:

- High-fidelity visualization  
- Physics-based animations  
- Human-robot interaction testing  

Steps:

1. Export robot URDF → Unity asset  
2. Integrate sensors (camera, depth, LiDAR)  
3. Apply physics  
4. Visualize AI behaviors in 3D

Unity is ideal for demonstrations and human-in-the-loop testing.
