# Robot Simulation Overview

Simulation is critical before deploying robots in the real world.

Two main environments:

1. **Gazebo**
   - Physics simulation: collisions, gravity, sensors  
   - Robot testing without hardware risks  

2. **Unity**
   - High-fidelity rendering  
   - Human-robot interaction  
   - Visualization of AI-driven behaviors

Simulations allow rapid testing, debugging, and training of robot AI.
