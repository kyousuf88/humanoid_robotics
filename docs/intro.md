# Physical AI & Humanoid Robotics

Welcome to **Physical AI**, where artificial intelligence steps out of the screen and into the physical world.

This course is designed to bridge:

- **AI models** → reasoning and decision-making  
- **Robotic bodies** → actuation, sensing, movement  
- **Simulated environments** → physics, interaction, training  
- **Real-world deployment** → SLAM, control, manipulation  

By the end of this course you will build a **fully autonomous humanoid robot system** capable of:

- understanding natural language  
- planning tasks  
- navigating obstacles  
- identifying objects  
- manipulating them using robotic hands  

using ROS 2, Gazebo, Unity, NVIDIA Isaac, and Vision-Language-Action (VLA) models.

This book guides you through every stage.
