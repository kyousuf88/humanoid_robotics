# Reinforcement Learning for Robots

RL allows robots to **learn behaviors** through trial and error:

- Define reward functions  
- Train in simulation (Gazebo/Isaac)  
- Transfer to real robot  

RL enables humanoids to learn walking, grasping, and navigation autonomously.
